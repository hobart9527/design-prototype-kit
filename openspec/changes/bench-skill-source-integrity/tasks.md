## 1. Refuse an incomplete skill source

- [ ] T-01 Refuse an incomplete skill source in the variant resolver and the baseline restore
  - Depends on: none
  - Anchors: benchmarks/runners/bench_lib.py:variant_sources, benchmarks/runners/bench_lib.py:ensure_baseline, benchmarks/runners/bench_lib.py:prepare_workspace
  - Write scope: benchmarks/runners/bench_lib.py, tests/test_benchmark_harness.py
  - Verify with: python3 -m pytest -q -p no:cacheprovider tests/test_benchmark_harness.py
  - Action: `variant_sources` returns `ROOT / "skills/spec-prototype"` for `candidate_skill` and returns the restored tree for `stable_skill` without inspecting either, so a resolved source missing its entry point is copied by `prepare_workspace` and measured as a normal arm. A frozen workspace built from a 37-file tree with no `SKILL.md` was reported as a `candidate_skill` run for this reason. Add one integrity contract for a resolved, non-`no_skill` skill source: `SKILL.md`, `CONTEXT.md`, `references/core-workflow.md`, and at least one file in `templates/`. Enforce it inside `variant_sources` so `prepare_workspace`, `run_matrix` and the CLI are all covered rather than the workspace path alone, and enforce the same contract on the restored baseline tree before it is returned. The refusal is `BenchBlocked` naming the resolved path and every missing entry, so an operator learns which contract member failed without inspecting the tree. Do not derive the contract from `benchmarks/baselines/*/MANIFEST.json`: a complete baseline legitimately has no `method-manifest.json` or `surface-map-manifest.json`, so a manifest-shaped check would refuse the valid control arm. Do not write or repair any file inside a refused source, and do not exempt any other variant than `no_skill`.
  - Proof: In temporary fixtures, assert that a source missing each required entry is refused with that entry named and that the refusal precedes any workspace mutation, that a complete source still prepares a workspace whose `SKILL.md` is a regular file, that a truncated baseline tree and an absent baseline tree each fail named rather than being measured, and that `no_skill` still resolves without a skill.
