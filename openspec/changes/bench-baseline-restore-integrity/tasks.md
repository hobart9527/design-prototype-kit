## 1. Hold both baseline exits to the integrity contract

- [ ] T-01 Refuse an incomplete or malformed baseline on every restore exit
  - Depends on: none
  - Anchors: benchmarks/runners/bench_lib.py:ensure_baseline, benchmarks/runners/bench_lib.py:skill_contract_gaps, benchmarks/runners/bench_lib.py:divergences
  - Write scope: benchmarks/runners/bench_lib.py, tests/test_benchmark_harness.py
  - Verify with: python3 -m pytest -q -p no:cacheprovider tests/test_benchmark_harness.py
  - Action: `ensure_baseline` returns two trees without holding either to the integrity contract. The cached exit guards `if not stale: require_complete_skill(...)`, but `divergences()` returns an empty list whenever `manifest["hashes"]` is empty, so a present-but-truncated cached tree is returned unchanged as the `stable_skill` control. The restore exit runs `require_complete_skill` only in the divergent branch, so an absent tree restored from `git archive` is returned unchecked. A third defect shares that path: `divergences()` reads `meta["sha256"]` without validating the entry, so a hash entry that is not a mapping carrying a string `sha256` raises `KeyError` rather than the documented `BenchBlocked`. Make `divergences()` treat every entry that is not a mapping with a string `sha256` as a divergence named by its relative path, and make both exit paths call `require_complete_skill` on the tree they are about to return, so the freshly restored tree is checked as well as the cached one. Keep the manifest divergence check on the restore path: the integrity contract proves the tree is shaped like a skill, the manifest proves it is the frozen revision. Do not add a new contract, do not change `REQUIRED_SKILL_ENTRIES`, do not repair a refused tree in place, and do not alter the `candidate_skill` path or the `no_skill` exemption.
  - Proof: In temporary baseline fixtures, assert that a truncated cached tree with an empty hashes map is refused naming the missing entries, that an absent tree restored from a plausible revision is refused when the recorded revision restores an incomplete tree, that a malformed hash entry is refused as a named divergence rather than raising `KeyError`, that a valid cached baseline and a valid absent baseline both still resolve, and that a tampered tree is still rebuilt rather than used.
