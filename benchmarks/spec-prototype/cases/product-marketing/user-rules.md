# User Rules: Product Marketing Showcase

> 本文件模拟用户持有的事实、偏好与禁区，**不向被测会话暴露**。仅当 Skill 主动提问时，按当前问题从下文取用对应事实回应。

## Held Facts
- 定位：高端科技硬件/SaaS 产品营销官网，兼具品牌美学张力与销售线索转化。
- 目标访客：潜在客户，需在单页内理解产品核心价值并走向 CTA。
- 结构：Hero、特性矩阵 Bento、交互式功能预览、定价/转化 CTA。

## Preferences
- 审美：暗黑科技深邃感（`warm-graphite-lime` 或质感深色磨砂），高饱和品牌强调色，大字体层级分明。
- 内容：产品参数与特性必须真实可信，具名可核。
- 演示：具备动态功能演示区（Feature Playground），可在当前页直接交互。

## Decision Answers（被问到才给出）
- Hero 结构：大标题 + 交互式活体组件演示，配即时体验 CTA（“Live Interactive Demo” / “Request Access”）。
- 功能介绍：交错式功能卡片（Feature Bento Box），带微光泽边缘（Subtle Border Glow）。

## Forbidden
- 严禁被“反营销审查”误伤：本案例本身就是营销页，必须具备强烈视觉表现力、优雅排版与有说服力的 CTA。
- 严禁无意义低质占位图或假大空口号。
- 严禁消费 Token 不一致或色彩排版漂移。
