# User Rules: AI Writer Workspace

> 本文件模拟用户持有的事实、偏好与禁区，**不向被测会话暴露**。仅当 Skill 主动提问时，按当前问题从下文取用对应事实回应。

## Held Facts
- 定位：AI 赋能的现代写作工作区（混合型基线：沉浸文本 + 伴随式决策抽屉）。
- 使用者：长篇作者，流程为 创作 -> AI 扩写/风格转译/事实校对 -> 差异对比 -> 选择性采纳/回滚。
- 形态约束：既非纯密集运维控制台，也非纯无状态长文阅读页，必须是有机“双轨工作台”。

## Preferences
- 审美：极简现代、温润微灰底色（`monochrome-pure` 或极轻微纸墨感），AI 变更用对比高亮。
- 布局：左侧宽编辑画布 + 右侧自适应收拢的 AI 协作侧栏。
- 反馈：AI 生成中须有骨架/呼吸态，状态切换流畅。

## Decision Answers（被问到才给出）
- 布局：左侧宽编辑画布 + 右侧自适应收拢的 AI 协作侧栏。
- 交互细节：AI 生成段落用绿色高亮（新增）与红色删除线（替换），提供直观的 `Accept` / `Reject` 按钮。

## Forbidden
- 严禁单一基线硬套：不得退化为纯密集运维控制台或纯无状态阅读页。
- 严禁生成中突兀白屏或界面假死。
- 采纳（Accept）与丢弃（Reject）必须支持一键快捷撤销（Undo）。
